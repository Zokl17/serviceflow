# ServiceFlow

Веб-сервис для оформления и управления заявками на выездное обслуживание.

Собственный pet-проект, разработанный на Django и PostgreSQL.

## Возможности

- создание заявки клиентом;
- категории услуг и неисправностей;
- назначение исполнителя;
- статусы заявок;
- история изменения статусов;
- административная панель;
- PostgreSQL;
- Docker Compose;
- адаптивный веб-интерфейс.

## Stack

Python • Django • PostgreSQL • Docker • Git • HTML • CSS
